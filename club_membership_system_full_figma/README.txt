CLUB MEMBERSHIP SYSTEM — EXPANDED FIGMA-STYLE VERSION

Requirements:
- XAMPP Apache and MySQL
- PHP and MySQL only; no JavaScript used.

SETUP:
1. Copy the folder to C:\xampp\htdocs\club_membership_system
2. Import database.sql using phpMyAdmin.
3. Keep your original user login/signup backgrounds in assets using:
   login-background.png
   signup-background.png
   form-background.png
4. Admin backgrounds are included:
   admin-signup-background.png
   admin-login-background.png
5. Start Apache and MySQL.
6. Open http://localhost/club_membership_system/

ADMIN SIGN UP:
- Open admin_signup.php.
- Admin registration code for this classroom/demo build: CLUBADMIN2026
- Change this code in admin_signup.php before using outside a local class project.

PAGES:
- login.php / signup.php
- admin_login.php / admin_signup.php
- dashboard.php / admin_dashboard.php
- logout.php / admin_logout.php

Note: Dashboard cards use sample counts for events/clubs until corresponding database tables and management functions are implemented. Layout is styled to approximate the provided Figma screenshots; pixel-perfect matching depends on the exact original background image files and viewport size.
